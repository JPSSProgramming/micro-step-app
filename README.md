# MicroStep

## English

### Description
MicroStep is a mobile productivity application built with Flutter. The project aims to eliminate procrastination by helping users decompose complex, overwhelming goals into small, actionable 5-minute tasks.

### Core Features
- Goal Creation and Management: Set long-term objectives with target deadlines.
- Task Decomposition: Break down goals into manageable sub-tasks.
- Focus Session Timer: Dedicated timer for completing individual micro-steps without distractions.
- Progress Visualization: Real-time track of overall goal completion based on finished steps.

### Tech Stack
- Framework: Flutter (Dart)
- State Management: Provider / Bloc
- Local Storage: Shared Preferences / Hive

## Українська

### Опис
MicroStep — це мобільний додаток для підвищення продуктивності, розроблений на Flutter. Проєкт покликаний усунути прокрастинацію шляхом розбиття складних і обсяжних цілей на маленькі 5-хвилинні кроки.

### Основні функції
- Створення та управління цілями: Встановлення довгострокових завдань із дедлайнами.
- Декомпозиція завдань: Розбиття великих цілей на підзавдання.
- Таймер фокусування: Таймер для виконання окремих мікрокроків без відволікань.
- Візуалізація прогресу: Відстеження стану виконання цілі у реальному часі.

### Технологічний стек
- Фреймворк: Flutter (Dart)
- Управління станом: Provider / Bloc
- Локальна база даних: Shared Preferences / Hive
